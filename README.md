# Проект Analysis of banking operations*
`* проект находится в стадии разработки.`

## Описание
Проект Analysis of banking operations - приложение для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.

## Возможности:
На данном этапе в модулях `views.py` и `utils.py` реализован функционал генерации JSON-ответа для главной страницы.

В модуле `services.py` реализованы функции позволяющие искать операции по подстроке в столбцах "Описание" и "Категории". Отформатированы логи.

В модуле `reports.py` реализована функция возвращающая отчёт трат по заданной категории за последние три месяца (от переданной даты). Добавлен модуль `decorators.py` в котором реализован декоратор `save_to_excel`. Декоратор записывает в файл результат, который возвращает функция, формирующая отчет.

## Установка и запуск:

### Установка
**1. Клонируйте репозиторий:**
```commandline
git clone https://github.com/evgenios33/analysis_of_banking_operations.git
```
**2. Установите зависимости:**
```commandline
pip install -r requirements.txt
```

### Подготовка данных
**Положите файлы c данными в папку `data/` в корне проекта:**
- `operations.xlsx`

Формат файлов должен соответствовать ожидаемой структуре.

### Запуск
```commandline
poetry run python -m src.main
```

## Логирование:
**Путь к файлу логов задаётся через переменную `LOG_FILE`:**
```commandline
export LOG_FILE=./logs/app.log
poetry run python -m src.main
```
Если переменная не задана, используется `./logs/app.log` по умолчанию.

## Тестирование:
Для тестирования проекта используется библиотека `pytest`. Все основные функции покрыты тестами, чтобы обеспечить корректность работы программы.

### Запуск тестов
**Запуск тестов осуществляется командой:**
```
poetry run pytest tests/
```

### Покрытие тестами
Код проекта покрыт тестами более чем на 80%, что позволяет уверенно говорить о его надежности.

### Отчеты покрытия
HTML-отчеты по покрытию тестами можно найти в папке `htmlcov` после выполнения команды:
```
poetry run pytest --cov=src --cov-report=html
```
